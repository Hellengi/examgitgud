# Выбор дисциплины и план подготовки

1. В личном кабинете откройте **«Моя сессия»** и выберите дисциплину из списка, например «Математический анализ».
2. Укажите дату экзамена из расписания сессии и желаемый балл.
3. Нажмите **«Составить план»**. Платформа распределит темы дисциплины по оставшимся дням: сначала темы, в которых у вас больше ошибок.
4. Отмечайте выполненные пункты плана — прогресс отображается полосой над планом.

> План пересчитывается автоматически раз в неделю по результатам ваших тренировок.
